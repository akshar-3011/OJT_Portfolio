# CodeWire Studio Portfolio

Your **new** agency portfolio — separate from the reference `ojt-project-s2-main` folder.

## Open it

Serve the **LIVE-NEWZ** root folder:

```bash
cd LIVE-NEWZ
npx serve .
```

Visit: **http://localhost:3000/portfolio/**

## What's inside

- **Overview** — hero + quick stats
- **Projects** — GlobalWire (Live-NEWZ) featured
- **Team** — editable member cards
- **GlobalWire** — live iframe preview
- **Contact** — form + email

## Customize (easy)

Edit **`portfolio/js/data.js`**:

- `AGENCY` — your studio name, tagline, email
- `PROJECTS` — add more builds
- `TEAM` — replace placeholder names, bios, GitHub/LinkedIn links, avatars

Put team photos in `portfolio/assets/` and update `avatar` paths.

## GlobalWire link

The app opens at `../index.html` (the main LIVE-NEWZ project).
