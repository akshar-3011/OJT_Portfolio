# GlobalWire (Live-NEWZ)

Real-time news web app — college project.

**Tech:** HTML, CSS, JavaScript, News API, Vercel

## Vercel deploy

1. Import `akshar-3011/OJT_Portfolio` on [vercel.com](https://vercel.com)
2. Branch: **develop**
3. Root Directory: **`projects/live-newz`**
4. Env variable: `NEWS_API_KEY` = your News API key
5. Deploy

## Local run

```bash
cd projects/live-newz
cp js/config.example.js js/config.js   # add your key
npm run dev
```
