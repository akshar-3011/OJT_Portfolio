# GlobalWire

Real-time global news tracker built with HTML, CSS, and JavaScript.

## Setup
1. Visit [newsapi.org](https://newsapi.org) and get an API key.
2. Copy `js/config.example.js` to `js/config.js`.
3. Replace `YOUR_NEWSAPI_KEY` with your NewsAPI key.
4. Open `index.html` through a local web server.

## Features
- Sidebar navigation with categories (Politics, Finance, World, India, etc.)
- Breaking news live ticker
- Trending section and hero top story
- Search with trending and recent suggestions
- Bookmark articles (localStorage)
- Dark black & white theme with smooth animations
- Responsive layout with mobile bottom navigation
